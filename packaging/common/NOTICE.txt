mpv_r Notice
============

mpv_r is a video review player distribution based on mpv.

mpv official site:

https://mpv.io/

mpv source code:

https://github.com/mpv-player/mpv

mpv manual:

https://mpv.io/manual/

Bundled mpv Builds
------------------

Mac v0.3 packages bundle a project-built Apple Silicon mpv v0.41.0 app bundle.
Intel Mac is not a v0.3 target. Earlier Mac preview packages used the
unofficial third-party macOS mpv build by stolendata, as linked from the mpv
installation page.

The published Windows v0.2.0 package bundles an unofficial third-party Windows
mpv build by shinchiro. The project-built Windows v0.3.0 candidate uses an
MSYS2 MINGW64 build of mpv v0.41.0, but it is not published while its runtime
DLL notices and corresponding-source materials are being prepared.

These bundled mpv builds are not official mpv-player builds. This project is
not affiliated with mpv-player, stolendata, shinchiro, or MSYS2, and this
distribution is not endorsed by those projects.
