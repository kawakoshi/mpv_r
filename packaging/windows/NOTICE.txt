mpv_r Windows Preview Notice
============================

mpv_r is a video review player distribution based on mpv.

This Windows Preview bundles an unofficial third-party Windows build by
shinchiro, as linked from the mpv installation page.

Build source page:

https://github.com/shinchiro/mpv-winbuild-cmake
