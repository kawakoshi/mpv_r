# mpv_r

`mpv_r` is a video review player for macOS and Windows. It packages mpv with
review-oriented settings for frame-by-frame checking, comparing adjacent files,
and taking screenshots.

The primary README is in Japanese: [README.md](README.md).

## Downloads

Use an app package under GitHub Releases **Assets**, not GitHub's automatic
`Source code (zip)` archive.

- macOS: `mpv_r-mac-v0.3.0.dmg` (published)
- Windows: `mpv_r-windows-v0.2.0.zip` (published)

The project-built Windows v0.3.0 candidate is not published yet. Its DLL
licenses and corresponding-source publication are being audited first.
