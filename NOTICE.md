# NOTICE

`mpv_r` is a video review player distribution based on mpv.

Japanese reference translation:

- `translations_ja/NOTICE_jp.md`

## mpv

mpv official site:

- https://mpv.io/

mpv source code:

- https://github.com/mpv-player/mpv

mpv manual:

- https://mpv.io/manual/

mpv license information:

- `LICENSES/mpv-Copyright.txt`
- `LICENSES/mpv-LICENSE.GPL.txt`
- `LICENSES/mpv-LICENSE.LGPL.txt`

mpv is GPLv2 or later by default. Builds made with GPL disabled may be
LGPLv2.1 or later. This project treats the bundled mpv builds as GPL-family
software unless a later build is explicitly documented otherwise.

## Bundled mpv Builds

Mac packages bundle the unofficial third-party macOS mpv build by stolendata,
as linked from the mpv installation page.

Build source page:

- https://laboratory.stolendata.net/~djinn/mpv_osx/

Windows packages bundle the unofficial third-party Windows mpv build by
shinchiro.

Build source page:

- https://github.com/shinchiro/mpv-winbuild-cmake

These bundled mpv builds are not official mpv-player builds. This project is
not affiliated with mpv-player, stolendata, or shinchiro, and this distribution
is not endorsed by those projects.

## mpv_r Configuration

The `mpv_r` configuration files and documentation are maintained by the author
of the original `mpv_r` note article.

Included configuration:

- `config/mac/mpv.conf`
- `config/mac/input.conf`
- `config/windows/mpv.conf`
- `config/windows/input.conf`

These files provide the review-oriented playback behavior, keyboard controls,
pause-on-open behavior, playlist looping, and screenshot settings used by this
preview.

## Package Generation

v0.2 packages are generated by:

- `packaging/scripts/build-mac.sh`
- `packaging/scripts/build-windows.sh`
- `packaging/scripts/build-all.sh`

These scripts assemble existing mpv builds, mpv_r configuration files, and
project documents into release zip files. They do not build mpv from source.

## Future Direction

The v0.x releases prioritize a working user experience. A later release will
investigate self-building mpv so the full build process can be documented and
reproduced directly by this project.
