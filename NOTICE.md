software unless a later build is explicitly documented otherwise.

## Bundled mpv Builds

Mac v0.3 packages bundle a project-built Apple Silicon mpv v0.41.0 app bundle.
Intel Mac is not a v0.3 target. Earlier Mac preview packages used the
unofficial third-party macOS mpv build by stolendata, as linked from the mpv
installation page.

Build source page:

- https://laboratory.stolendata.net/~djinn/mpv_osx/

Windows v0.3.0 bundles an MSYS2 MINGW64 build of mpv v0.41.0 built by this
project. Its runtime DLL manifests, license texts, source index, and build
records are included in the portable ZIP; matching corresponding-source
archives are provided with the release. The earlier Windows v0.2.0 package
used an unofficial third-party Windows mpv build by shinchiro.

Build source page:

- https://github.com/shinchiro/mpv-winbuild-cmake

These bundled mpv builds are not official mpv-player builds. This project is
not affiliated with mpv-player, stolendata, shinchiro, or MSYS2, and this
distribution is not endorsed by those projects.

## mpv_r Configuration

The `mpv_r` configuration files and documentation are maintained by the author
of the original `mpv_r` note article.

Included configuration:

- `config/mac/mpv.conf`
- `config/mac/input.conf`
- `config/windows/mpv.conf`
- `config/windows/input.conf`

These files provide the review-oriented playback behavior, keyboard controls,
pause-on-open behavior, playlist looping, and screenshot settings used by this
preview.

## Package Generation

v0.3 packages are generated by:

- `packaging/scripts/build-mac.sh`
- `packaging/scripts/build-windows.sh`
- `packaging/scripts/build-all.sh`

The Mac package is assembled from a project-built Apple Silicon mpv app bundle
and exported as a DMG. The Windows v0.3.0 package assembles a verified
project-built MSYS2 runtime, configuration, documents, DLL manifests, and
license evidence into a portable ZIP. The release procedure and verification
requirements are recorded in `docs/windows-selfbuild-license-audit.md`.

## Future Direction

The v0.x releases prioritize a working user experience. A later release will
prepare a Windows installer; v0.3.0 remains a portable ZIP.
