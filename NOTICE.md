# NOTICE

`mpv_r` is a video review player distribution based on mpv.

## mpv

This release bundles mpv `0.39.0`.

mpv official site:

- https://mpv.io/

mpv source code:

- https://github.com/mpv-player/mpv

mpv license information:

- `LICENSES/mpv-Copyright.txt`
- `LICENSES/mpv-LICENSE.GPL.txt`
- `LICENSES/mpv-LICENSE.LGPL.txt`

mpv is GPLv2 or later by default. Builds made with GPL disabled may be LGPLv2.1 or later. This v0.1.0 distribution treats the bundled mpv app as GPL-family software and includes the corresponding license texts and source links.

## macOS Build Source

This v0.1.0 Mac Preview bundles the unofficial third-party macOS build by stolendata, as linked from the mpv installation page.

Build source page:

- https://laboratory.stolendata.net/~djinn/mpv_osx/

Downloaded archive:

- `mpv-latest.tar.gz`

Bundled mpv version:

- `0.39.0`

The stolendata build is not an official mpv-player build. This project is not affiliated with mpv-player or stolendata, and this distribution is not endorsed by either project.

## mpv_r Configuration

The `mpv_r` configuration files and documentation are maintained by the author of the original `mpv_r` note article.

Included configuration:

- `config/mac/mpv.conf`
- `config/mac/input.conf`

These files provide the review-oriented playback behavior, keyboard controls, pause-on-open behavior, playlist looping, and screenshot settings used by this preview.

## Future Direction

The v0.1.x releases prioritize a working user experience. A later release will investigate self-building mpv so that the full build process can be documented and reproduced directly by this project.
