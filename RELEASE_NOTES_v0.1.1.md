# mpv_r v0.1.1 - Windows Preview

This is the first public Windows Preview of `mpv_r`.

It packages the author's original `mpv_r` review setup as a downloadable Windows 64-bit app folder.

Japanese reference translation:

- `translations_ja/RELEASE_NOTES_v0.1.1_jp.md`

## Download

Download:

- `mpv_r-windows-v0.1.1.zip`

Use the attached app zip under Release assets. Do not download GitHub's automatic `Source code (zip)` if you want to run the app.

## What's Included

- `mpv_r.exe`
- bundled `mpv/mpv.exe`
- `portable_config` with renewed `mpv_r` configuration files
- README and install notes
- mpv license texts and source/build links

## Notes

- Windows 64-bit only.
- This is a preview release.
- This release bundles the unofficial third-party Windows build by shinchiro.
- This project is not affiliated with mpv-player or shinchiro.
- The launcher is not code-signed. Windows SmartScreen behavior may vary.

## Smoke Test

The v0.1.1 package was manually smoke-tested on Windows:

- `mpv_r.exe` launches.
- No black console window appears.
- Video files open.
- Primary keyboard controls work.
- Screenshots save to the Desktop.
