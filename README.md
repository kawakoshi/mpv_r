# mpv_r

`mpv_r` is a video review player for Mac and Windows.

It packages mpv with the author's review-oriented settings so video files can
be checked frame by frame, compared across adjacent files, and captured as
screenshots with minimal setup.

Japanese reference translations are available in `translations_ja/`.

The English files are the authoritative versions. Japanese files are reference
translations prepared to help review and understanding.

## Downloads

Download app zips from GitHub Releases:

- `mpv_r-mac-v0.2.0.zip`
- `mpv_r-windows-v0.2.0.zip`

Do not download GitHub's automatic `Source code (zip)` archive if you want to
run the app. Use the zip attached under Release assets.

## Package Layout

v0.2 packages use the same top-level shape on Mac and Windows:

```text
mpv_r/
  mpv_r.app or mpv_r.exe
  resources/
  documents/
```

`resources` contains bundled runtime files and mpv_r configuration.

`documents` contains README, NOTICE, license texts, source/build information,
keyboard shortcuts, and Japanese reference translations.

## Open Videos

- Drag one or more video files onto `mpv_r.app` or `mpv_r.exe`.
- Or open a video file from mpv_r.

Multiple files are loaded as a playlist.

## Included mpv Builds

Mac packages bundle the unofficial third-party macOS mpv build by stolendata.

Windows packages bundle the unofficial third-party Windows mpv build by
shinchiro.

This project is not affiliated with mpv-player, stolendata, or shinchiro.

See `NOTICE.md` and `LICENSES/` for license, attribution, and source/build
information.

## Source Configuration

The bundled configuration is kept in:

- `config/mac/mpv.conf`
- `config/mac/input.conf`
- `config/windows/mpv.conf`
- `config/windows/input.conf`

## Packaging

v0.2 packages are generated by:

- `packaging/scripts/build-mac.sh`
- `packaging/scripts/build-windows.sh`
- `packaging/scripts/build-all.sh`

These scripts assemble existing mpv builds, mpv_r configuration files, and
project documents into release zip files. They do not build mpv from source.
