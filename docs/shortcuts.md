# Shortcuts

This preview keeps the original `mpv_r` style controls.

| Key | Action |
| --- | --- |
| `Space` / numpad `0` | Play / pause |
| `Left` | Previous frame |
| `Right` | Next frame |
| `Up` | Previous file |
| `Down` | Next file |
| `Shift + Left` | Seek back 1 second |
| `Shift + Right` | Seek forward 1 second |
| `Shift + Up` | Seek back 30 seconds |
| `Shift + Down` | Seek forward 30 seconds |
| `/` | Screenshot |
| `f` / `*` | Fullscreen |
| `Esc` | Exit fullscreen |
| `Command + W` / `Control + W` | Quit |

Screenshots are saved to the Desktop.
