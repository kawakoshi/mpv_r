# Troubleshooting

Japanese reference translation:

- `../translations_ja/troubleshooting_jp.md`

## macOS says the app cannot be opened

This v0.1.0 preview is not notarized.

Right-click `mpv_r.app`, choose `Open`, then choose `Open` again in the warning dialog.

## I downloaded Source code instead of the app

On GitHub Releases, download `mpv_r-mac-v0.1.0.zip` from Release assets.

Do not use GitHub's automatic `Source code (zip)` archive if you want the app.

## Screenshots are not where I expected

Screenshots are saved to the Desktop.

## A video does not play

Please include the file format, macOS version, and what happened when reporting the issue.
