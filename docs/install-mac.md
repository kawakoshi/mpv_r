# Install on macOS

Japanese reference translation:

- `../translations_ja/install-mac_jp.md`

1. Download `mpv_r-mac-v0.1.0.zip` from GitHub Releases.
2. Unzip the archive.
3. Move `mpv_r.app` to `/Applications`.
4. Right-click `mpv_r.app` and choose `Open`.
5. If macOS shows a warning, choose `Open` again.

After the first launch, you can usually open the app normally.

## Open a Video

- Drag video files onto `mpv_r.app`.
- Or right-click a video file and choose `Open With` -> `mpv_r`.

## If macOS Blocks the App

This preview is not notarized. If macOS blocks the app, use right-click -> `Open`.
