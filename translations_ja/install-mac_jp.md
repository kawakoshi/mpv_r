1. GitHub Releasesから`mpv_r-mac-v0.1.0.zip`をダウンロードします。
2. zipを展開します。
3. `mpv_r.app`を`/Applications`へ移動します。
4. `mpv_r.app`を右クリックして`開く`を選びます。
5. macOSの警告が出た場合は、もう一度`開く`を選びます。

初回起動後は、通常どおりアプリを開ける場合が多いです。

## 動画を開く

- 動画ファイルを`mpv_r.app`へドラッグ&ドロップします。
- または、動画ファイルを右クリックし、`このアプリケーションで開く`から`mpv_r`を選びます。

## macOSにブロックされた場合

このv0.1.0 Previewはnotarizationを行っていません。

macOSにブロックされた場合は、右クリックして`開く`を選んでください。
