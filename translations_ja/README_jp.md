# mpv_r 日本語参考文書

このリポジトリの正面READMEは、日本語を先に、その後に英語を掲載しています。
現在のダウンロード、使い方、公開状況はリポジトリ直下の`README.md`を参照してください。

ライセンス、NOTICE、ソース／ビルド情報は、配布物に入る英語原文を正本とします。
このファイルを含む`translations_ja/`配下の文書は、日本語での確認と理解を助けるための参考文書です。

## v0.3.0

- Mac：Apple Silicon向けDMG。自前ビルドしたmpv v0.41.0を同梱します。
- Windows：64-bit向けポータブルZIP。MSYS2上で自前ビルドしたmpv v0.41.0を同梱します。
- Windows版はインストーラーではありません。展開したフォルダ一式を保ち、同梱cmdで作成したデスクトップショートカットへ動画をドラッグ&ドロップする使い方を推奨します。
- Windows版のランタイムDLL、ライセンス、対応ソース、最終パッケージの検証記録を収録します。

詳しい手順：

- Mac：`RELEASE_NOTES_v0.3.0_jp.md`
- Windows：`windows-preview-guide_jp.md`
- キーボード操作：`shortcuts_jp.md`

## 注意

- Macアプリはad-hoc署名済みですがnotarizeはしていません。
- Windowsのランチャーと同梱mpvにはコード署名がありません。
- OSの警告が表示された場合は、このプロジェクトのRelease assetsから取得したファイルであることと、公開SHA-256が一致することを確認してください。
