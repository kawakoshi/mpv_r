## ダウンロード

ダウンロード:

- `mpv_r-windows-v0.1.1.zip`

アプリとして使う場合は、Release assetsに添付されたzipを使ってください。GitHubが自動生成する`Source code (zip)`はアプリ本体ではありません。

## 同梱内容

- `mpv_r.exe`
- 同梱された`mpv/mpv.exe`
- 更新した`mpv_r`設定ファイルを含む`portable_config`
- READMEとインストールメモ
- `translations_ja`内の日本語参考訳
- mpvのライセンス文書、ソース/ビルド情報リンク

## 注意

- Windows 64-bit専用です。
- これはプレビューリリースです。
- このリリースには、shinchiroによる非公式の第三者Windowsビルドを同梱しています。
- このプロジェクトはmpv-playerまたはshinchiroとは関係ありません。
- ランチャーはコード署名されていません。Windows SmartScreenの挙動は環境によって異なる場合があります。

## 簡易テスト

v0.1.1パッケージはWindowsで手動の簡易テストを行いました。

- `mpv_r.exe`が起動する。
- 黒いコンソールウィンドウが表示されない。
- 動画ファイルを開ける。
- 主なキーボード操作が動作する。
- スクリーンショットがデスクトップに保存される。
