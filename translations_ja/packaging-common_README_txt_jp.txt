mpv_rは、MacとWindows向けの動画レビュー用プレイヤーです。

mpvに作者のレビュー向け設定を組み合わせ、動画をフレーム単位で確認したり、
前後のファイルを見比べたり、スクリーンショットを残したりできるようにした
配布版です。

起動
----

Mac:

1. DMGを開きます。
2. `mpv_r.app`を`Applications`へドラッグします。
3. `mpv_r.app`を開きます。
4. 初回起動時にmacOSで止められる場合は、`mpv_r.app`を右クリックして`開く`を選びます。
5. その後、macOSが動画をファイル名でブロックした場合は、`システム設定` >
   `プライバシーとセキュリティ`で、その信頼できる動画に対する`このまま開く`を選び、
   求められた場合は認証します。ダウンロードした動画にmacOSの隔離情報が残っていると、
   この確認が表示されることがあります。

`このまま開く`は、信頼できる入手元の動画に対してのみ選んでください。

Windows:

1. zipを展開します。
2. `mpv_r`フォルダを開きます。
3. `create-desktop-shortcut.cmd`を実行し、新しいショートカットへ動画をドラッグ&ドロップします。または`mpv_r.exe`へ直接ドラッグ&ドロップします。
4. Windows SmartScreenが表示された場合は、このプロジェクトのRelease assetsから取得し、公開SHA-256と一致するファイルだけを続行してください。

動画を開く
----------

- 1つまたは複数の動画ファイルを`mpv_r.app`または`mpv_r.exe`へドラッグ&ドロップします。
- またはmpv_rから動画ファイルを開きます。

複数ファイルはプレイリストとして読み込まれます。

ショートカット
--------------

キーボードショートカットは以下に含まれます。

- `documents/shortcuts.md`
