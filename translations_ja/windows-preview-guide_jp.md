## 対象

現在のWindows版は`v0.2.0`です。インストーラーではなく、64-bit向けのポータブルZIPパッケージです。展開したフォルダは一式を保ったまま使ってください。通常の利用にセットアッププログラムや管理者権限は必要ありません。

## 起動

1. GitHub Releasesから`mpv_r-windows-v0.2.0.zip`をダウンロードします。GitHubが自動生成する`Source code (zip)`は使いません。
2. ZIPを`Documents`や`Downloads`など書き込み可能な場所へ展開します。
3. 展開した`mpv_r`フォルダを開きます。
4. `mpv_r.exe`を起動するか、1つまたは複数の動画ファイルを`mpv_r.exe`へドラッグ&ドロップします。

複数のファイルはプレイリストとして読み込まれます。mpv_rは初期状態で一時停止して開きます。

## パッケージを一式で保つ

`mpv_r.exe`は、同梱された`resources/mpv/mpv.exe`を起動し、`resources/config`の設定を読み込みます。`mpv_r.exe`だけを移動せず、展開した`mpv_r`フォルダ全体を移動またはコピーしてください。

```text
mpv_r/
  mpv_r.exe
  resources/
    mpv/
    config/
  documents/
```

## レビュー操作

| キー | 操作 |
| --- | --- |
| `Space`またはテンキー`0` | 再生 / 一時停止 |
| Left / Right | 前 / 次のフレーム |
| Up / Down | プレイリストの前 / 次のファイル |
| `Shift` + Left / Right | 1秒戻る / 進む |
| `Shift` + Up / Down | 30秒戻る / 進む |
| `/` | PNGスクリーンショットをDesktopへ保存 |
| `f`または`*` | フルスクリーン切替 |
| `Esc` | フルスクリーン解除 |
| `Ctrl` + `W` | 終了 |

完全な設定は`resources/config`にあります。同梱のショートカット一覧は`documents/shortcuts.md`です。

## Windowsのセキュリティ通知

ランチャーにはコード署名がありません。WindowsでSmartScreen警告が表示される場合があります。プロジェクトのGitHub Releasesページからダウンロードし、公開されているSHA-256とダウンロード済みZIPが一致する場合だけ続行してください。

## トラブルシューティング

- **「mpv executable not found」** — 展開した`mpv_r`フォルダ一式を復元してください。`mpv_r.exe`だけをコピーして実行しないでください。
- **動画を開けない** — まず`mpv_r.exe`を起動して開く操作を使うか、実行ファイルへドラッグ&ドロップしてください。特別なアクセス権が必要な場所ではないローカルファイルで試してください。
- **スクリーンショットが見つからない** — PNGは、元ファイル名とタイムコードを含む名前で、ログイン中のユーザーのDesktopに保存されます。
- **設定を戻したい** — 新しく展開したパッケージから、元の`resources/config/mpv.conf`と`resources/config/input.conf`を復元してください。

## 制限事項

- Windows 64-bit専用です。
- これはプレビューリリースです。
- このプロジェクトはmpv-playerまたはshinchiroとは関係ありません。ライセンスおよびソース/ビルド情報は`documents`に含まれます。
