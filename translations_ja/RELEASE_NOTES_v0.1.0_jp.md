## ダウンロード

ダウンロード:

- `mpv_r-mac-v0.1.0.zip`

Release assetsに添付されているアプリ配布zipを使用してください。アプリを実行したい場合、GitHubが自動生成する`Source code (zip)`はダウンロードしないでください。

## 同梱内容

- `mpv_r.app`
- READMEとインストールメモ
- mpvのライセンス本文とソースコードリンク
- 更新した`mpv_r`設定ファイル

## 注意

- macOSのみ対応。
- アプリはad-hoc署名済みですが、notarizationは行っていません。
- 初回起動時は、アプリを右クリックして`開く`を選んでください。
- このリリースは、stolendataによるmacOS向け非公式third-party buildを使用してmpv `0.39.0`を同梱しています。
- 本プロジェクトはmpv-playerおよびstolendataとは無関係です。
