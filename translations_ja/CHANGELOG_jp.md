## v0.3.0 - Mac／Windows自前ビルドランタイム

- Apple Silicon Mac向けに、自前ビルドしたmpv v0.41.0を含むDMGを追加。
- Windows 64-bit向けに、自前ビルドしたMSYS2版mpv v0.41.0を含むポータブルZIPを追加。
- Windowsにデスクトップショートカット作成と、現在のユーザー向け関連付け登録を追加。
- Windows ZIPにランタイム、ソース、ライセンス、最終パッケージの一覧を収録。
- ソース索引87行、Windowsランタイム130本、最終バイナリ131本、ライセンス文書163件を検証。
- 一致する対応ソースを別のRelease assetとして公開。
- Macアプリはad-hoc署名済みですがnotarizeなし、Windowsバイナリはコード署名なしのため、OSのセキュリティ確認が表示される場合があります。

## v0.1.1 - Windows Preview

Windows 64-bit向けの最初の公開Previewです。

- shinchiroによるWindows x86_64版mpvビルドを同梱。
- Windowsでわかりやすく起動するための小さなGo製ランチャー`mpv_r.exe`を追加。
- 同梱したレビュー用設定がアプリフォルダ内に残るよう、`portable_config`を使用。
- Mac v0.1.0設定をもとに更新した`mpv_r`キーボード操作を同梱。
- スクリーンショットをユーザーのデスクトップへ保存。
- mpvのライセンス文書、著作権表示、ソース/ビルド情報リンクを同梱。

簡易テスト:

- Windowsで、起動、黒いコンソールウィンドウが出ないこと、動画を開けること、主要キー操作、デスクトップへのスクリーンショット保存を確認済み。
- 最初の手動テストではWindows SmartScreenによるブロックはありませんでしたが、ランチャーはコード署名されていないため、挙動は環境によって異なる場合があります。

## v0.1.0 - Mac Preview

macOS向けの最初の公開Previewです。

- stolendataによるmacOS向け非公式ビルドを使用し、mpv `0.39.0`を同梱。
- 確認作業向けに更新した`mpv_r`設定を同梱。
- `mpv_r.app`へのファイルドラッグ&ドロップに対応。
- 複数ファイルをプレイリストとして開く。
- 起動時は一時停止し、再生終了後もウィンドウを閉じない。
- スクリーンショットをデスクトップへ保存。
- mpvのライセンス文書、著作権表示、ソースコードリンクを同梱。

既知の注意:

- アプリはad-hoc署名済みですが、notarizationは行っていません。
- 初回起動時は、macOSで右クリックして`開く`を選ぶ必要がある場合があります。
- Windows対応はv0.1.1で予定しています。
