## macOSでアプリを開けないと言われる

このv0.1.0 Previewはnotarizationを行っていません。

`mpv_r.app`を右クリックして`開く`を選び、警告ダイアログでもう一度`開く`を選んでください。

## アプリではなくSource codeをダウンロードしてしまった

GitHub Releasesでは、Release assetsにある`mpv_r-mac-v0.1.0.zip`をダウンロードしてください。

アプリを使いたい場合、GitHubが自動生成する`Source code (zip)`は使いません。

## スクリーンショットが見つからない

スクリーンショットはデスクトップに保存されます。

## 動画が再生されない

Issueで報告する場合は、ファイル形式、macOSのバージョン、何が起きたかを含めてください。
